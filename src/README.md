# 포켓몬 도감 관리 시스템 

Java 콘솔 환경에서 구동되는 포켓몬 도감 관리 시스템입니다.
포켓몬 정보의 추가, 삭제, 조건별 필터링, 정렬 기능 및 파일 영속성 저장 기능을 제공합니다.

##  개발 환경 및 활용 기술
- **Language**: Java 17 이상 권장
- **IDE**: IntelliJ IDEA / Eclipse
- **자료구조 (Data Structure)**:
    - `HashMap`: 도감 번호(ID)를 Key값으로 지정하여 $O(1)$의 시간 복잡도로 빠르게 추가/삭제/검색이 가능하게 구현
    - `ArrayList`: 정렬, 필터링 및 전체 목록 출력을 위해 유연한 동적 배열 활용

---

## 주요 핵심 기능

### 1. 포켓몬 기본 관리
- **포켓몬 추가/삭제**: 도감 번호 중복을 검사하고 객체를 추가 및 삭제 처리합니다.
- **포획 여부 설정**: 잡은 포켓몬과 잡지 않은 포켓몬의 유동적 상태 변경 기능.

### 2. 다채로운 필터링 및 조회 (요구사항 반영)
- **전체 목록**: 도감 번호 순 정렬 출력.
- **이름 검색**: 포함어(Contains) 매칭을 통한 검색.
- **타입별 & 세대별 필터링**: 불꽃, 물, 풀 등 원하는 속성 및 세대별 모아보기 제공.
- **명예의 전당 (Top 6)**: 등록된 포켓몬 중 **전투력(CP)이 가장 높은 6마리**를 내림차순 정렬하여 출력.
- **포획 완료 목록**: 현재 소지/포획 완료한 포켓몬 리스트만 따로 스캔.

### 3. 통계 및 추가 기능
- **타입별 평균 전투력 계산**: 각 타입별 포켓몬의 평균 CP 통계를 산출합니다.
- **[추가기능] 도감 달성률 제공**: 전체 등록 개수 대비 포획한 수의 퍼센티지(%) 연산.
- **Txt 파일 저장/불러오기**: 프로그램 종료 시 `pokedex.txt`에 자동 백업되며, 실행 시 자동으로 데이터를 복원합니다.

---

## 실행 방법
1. `src/Main.java` 파일을 실행합니다.
2. 콘솔창에 나타나는 메뉴 번호(0~11)를 입력하여 가이드에 맞춰 조작합니다.
3. 데이터는 프로젝트 루트 폴더 내 `pokedex.txt` 파일로 안전하게 자동 누적 저장됩니다.
